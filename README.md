# JiuCards

Android-App zum Lernen von 176 Jiu-Jitsu- und Judo-Techniken mit Karteikarten, Bildern, lokalen Videos und zeitlich abgestimmten Wiederholungen.

## Installation

Die APK unter [Releases](https://github.com/Endopterygota/JiuJitsuApp/releases/latest) herunterladen und auf Android installieren. Android kann dafür die Erlaubnis „Unbekannte Apps installieren“ verlangen.

## Funktionen

- Technikbibliothek mit 127 bebilderten Techniken und 66 lokalen Technikvideos.
- Bild-/Videokarte per Wischgeste oder Drehbutton umdrehen.
- Lernbewertungen: Nochmal, Schwer, Gut und Leicht; Gut hat einen längeren Abstand als Schwer.
- Quellenangaben für Medien, soweit vorhanden.

## Hinweise zu v1.4.0

Diese Veröffentlichung verwendet die vorhandene APK unverändert. Ihre interne Versionsnummer lautet weiterhin 1.3.0 (Build 4). Die APK ist lokal mit einem Android-Debugschlüssel signiert; ein Update einer anders signierten Installation ist nicht möglich. Vor einer etwaigen Deinstallation den Lernfortschritt sichern.

## Entwicklung

React Native / Expo und TypeScript. Abhängigkeiten mit `npm ci` installieren, die Entwicklungsumgebung mit `npx expo start` starten. Der GitHub-Quellcode kann vom separat lokal erstellten APK-Stand abweichen.
